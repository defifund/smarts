# What is Smarts.md?

Smarts.md turns verified smart-contract data into clean, readable markdown.

It helps people do three things:

1. Read contract docs faster.
2. Inspect live on-chain state without digging through raw ABIs.
3. Share article-style explanations that are easy for both humans and AI to parse.

Smarts.md is built for DeFi researchers, protocol builders, and anyone who wants a clearer view of on-chain systems.

Any verified contract. Smarts.md makes it clear.
