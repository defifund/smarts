# 为什么我做 Smarts.md

读合约文档是件很碎的事。

想搞清楚一个 Uniswap 池现在的费率、tick、流动性，要在 Etherscan 的 read 标签、协议官网、Dune 看板之间反复跳。每个工具看到的是片段，没有一个地方把"这个合约现在是什么样"完整讲明白。

Mintlify 这类工具走的是另一条路：把 git 仓库变成漂亮的文档站。但合约的真实状态不在 git 里——它在链上，每个区块都在变。

Smarts.md 想做的事很简单：

- 给每个已验证合约一个固定 URL，一打开就是它**此刻**的样子。
- 同一个 URL 自带 MCP 端点，Claude、Cursor 这些 AI 工具可以直接读它的状态。
- 文档是合约的实时投影，不是某个时间点的快照。

这是写给 DeFi 研究者的，也是写给越来越多用 AI 读链的人的。
