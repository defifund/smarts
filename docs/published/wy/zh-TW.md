# 為什麼我做 Smarts.md

讀合約文件是件很碎的事。

想搞清楚一個 Uniswap 池現在的費率、tick、流動性，要在 Etherscan 的 Read 頁籤、協議官網、Dune 看板之間反覆跳。每個工具看到的是片段，沒有一個地方把「這個合約現在是什麼樣」完整講明白。

Mintlify 這類工具走的是另一條路：把 git 倉庫變成漂亮的文件站。但合約的真實狀態不在 git 裡——它在鏈上，每個區塊都在變。

Smarts.md 想做的事很簡單：

- 給每個已驗證合約一個固定 URL，一打開就是它**此刻**的樣子。
- 同一個 URL 自帶 MCP 端點，Claude、Cursor 這些 AI 工具可以直接讀它的狀態。
- 文件是合約的即時投影，不是某個時間點的快照。

這是寫給 DeFi 研究者的，也是寫給越來越多用 AI 讀鏈的人的。
